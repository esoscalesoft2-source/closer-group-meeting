Razorpay tells this site directly when a payment succeeds, so a buyer who pays and closes the tab is still recorded.

This is a localhost address, and Razorpay can't reach your computer. The webhook works once the site is live on a public https address (or set PUBLIC_URL in .env to that address).

  2. Paste the Webhook URL above and the same secret.
  3. Tick the events payment.captured and order.paid, then save there and here.
